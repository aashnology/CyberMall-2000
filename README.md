# CyberMall 2000
Mood-first 3D digital mall (laptop only: keyboard + mouse). React + TypeScript + Three.js.

    npm install
    npm run dev        # http://localhost:5173
    npm test           # recommendation + pincode unit tests
    npm run typecheck

Tune scoring in `src/recommendation/weights.ts`. Brand logos load at runtime from the web; a text wordmark shows if offline.
Git identity is set per-repo to Aashna (`git config user.name`).
